# OrgMate 사용자 매뉴얼

회의를 녹음하면 자동으로 전사하고, 선택한 템플릿에 맞춰 회의록으로 정리해 주는 앱입니다. 현재 Android만 지원합니다.

## 1. 설치

1. Android 폰에서 아래 링크를 열어 APK를 내려받습니다.
   - https://expo.dev/artifacts/eas/BHtY2N7YSMRd-p_RRXr55RqnJ9aC2xbDcqpbJAyG27g.apk
2. 설치 시 "출처를 알 수 없는 앱" 허용을 요청하면 허용합니다.
3. 설치 후 OrgMate를 실행하고 마이크 권한을 허용합니다.

## 2. 로그인

1. 첫 화면에서 **조직 계정으로 로그인**을 누릅니다.
2. 조직(Microsoft Entra ID) 계정으로 로그인합니다. 등록된 조직 계정만 사용할 수 있습니다.
3. 로그아웃은 설정 시트의 **로그아웃**에서 합니다.

## 3. 녹음

1. 메인 화면에서 **녹음 시작**을 누릅니다.
2. 녹음 중에는 일정 시간 단위로 자동 분할되어 업로드 준비가 됩니다. 화면에 "녹음 중 · N분 단위 자동 분할"이 표시됩니다.
3. 끝나면 **녹음 중지**를 누릅니다. 업로드와 전사가 자동으로 이어집니다.

## 4. 전사와 정리

세션 카드의 상태 배지로 진행 상황을 확인합니다.

| 상태 | 의미 |
| --- | --- |
| 녹음 중 | 녹음이 진행되고 있음 |
| 전사 대기 | 업로드 완료, 전사 순서를 기다리는 중 |
| 전사 중 | 음성을 글로 변환하는 중 |
| 전사 완료 | 전사 끝. 정리 가능 |
| 정리 중 | 템플릿에 맞춰 요약 중 |
| 정리 완료 | 회의록 완성 |
| 실패 | 처리 실패. 아래 문제 해결 참고 |
| 중단됨 | 일정 시간 동안 진행이 없는 상태 |

정리 방법:

1. **정리 템플릿** 영역에서 원하는 템플릿을 고릅니다.
2. 전사가 끝난 세션 카드에서 **(템플릿 이름)으로 정리**를 누릅니다.
3. 정리 완료 후 **결과 보기**로 회의록을 확인하고, **공유**로 다른 앱에 보낼 수 있습니다.

## 5. 세션 관리

- **더보기**: 보관, 삭제 등 추가 동작을 엽니다.
- **보관 / 보관 해제**: 목록에서 숨깁니다. **보관함 포함**을 누르면 보관한 세션도 함께 보입니다.
- **삭제**: 녹음 파일, 전사본, 정리본을 모두 영구 삭제합니다. 되돌릴 수 없습니다.
- **전사 시작**: 전사가 안 된 세션의 전사를 다시 시작합니다.

## 6. 용어 사전

사내 용어나 이름이 잘못 전사될 때 설정 시트의 **용어 사전 > 관리**에서 정식 용어와 오인식 표기를 등록합니다. 이후 전사 결과에 반영됩니다.

## 7. 관리자 기능

관리자 권한이 있는 계정은 용어 사전과 정리 템플릿을 관리할 수 있습니다.

- 설정 시트의 **관리자 API 확인**으로 관리자 권한이 정상인지 확인합니다.
- `/api/manage` 웹 관리자 페이지는 브라우저 로그인을 지원하지 않아 현재 브라우저로 열면 401이 표시됩니다(정상 동작). 용어 사전은 앱에서 관리하고, 템플릿 관리는 인증 토큰을 담은 API 호출(`/api/templates`)로 합니다.

## 8. 녹음 및 개인정보 안내

- **녹음 전에 회의 참석자 모두에게 녹음 사실을 알리고 동의를 받아야 합니다.** 이는 녹음하는 사용자의 책임이며, 앱은 별도의 동의 화면을 제공하지 않습니다.
- 녹음 파일(오디오)은 업로드 후 30일이 지나면 자동으로 삭제됩니다.
- 전사본과 정리된 회의록은 마지막 수정 후 1년이 지나면 자동으로 삭제됩니다. 오래 보관해야 하는 내용은 **공유**로 내보내 두세요.
- 직접 **삭제**하면 즉시 영구 삭제되며, 삭제된 데이터는 백업 보존 기간 동안 시스템에 일시적으로 남을 수 있습니다.
- 다른 사용자는 내 세션을 볼 수 없습니다. 관리자도 마찬가지입니다.

## 9. 문제 해결

| 증상 | 조치 |
| --- | --- |
| 로그인이 안 됨 | 조직 계정인지 확인하고, 앱을 완전히 종료한 뒤 다시 실행합니다. |
| 상태가 오래 "전사 대기/전사 중"임 | 몇 분 기다린 뒤 새로 고칩니다. 계속되면 **전사 시작**을 다시 누릅니다. |
| 상태가 "실패" | **전사 시작** 또는 정리를 다시 시도합니다. 반복되면 운영 담당자에게 세션 제목과 시간을 알려 주세요. |
| 용어가 계속 잘못 전사됨 | 용어 사전에 오인식 표기를 추가합니다. |
| 마이크 권한 오류 | Android 설정 > 앱 > OrgMate > 권한에서 마이크를 허용합니다. |

운영 담당자는 [운영 절차서](operations/operations-runbook.md)를 참고하세요.
